# Changelog

## 1.8.0

- Added the Statistics sidebar page within the existing application window.
- Added Today, Last 7 days, Last 30 days, and custom date ranges for File System statistics.
- Added per-file daily and hourly charts for downloads and bandwidth.
- Added ranking, search, CSV export, optional 60-second refresh, and cancellable statistics scans.
- Kept My files lifetime statistics separate from dated File System statistics.
- Added explicit unavailable and partial-result states for failed statistics requests.
- Verified 150 checks across x64 and x86 processes.

## 1.7.2

- Changed all honeycomb backgrounds to regular hexagons.
- Removed the repeated background strip beneath the File System heading.
- Added faded heading edges while retaining Gray and Dark themes.

## 1.7.1

- Fixed recognition of existing website share links when the API omits `link_permissions`.
- Applied PixelDrain's default read-only link behavior while respecting explicit restrictions.
- Kept inherited sharing and sharing filters consistent with direct links.

## 1.7.0

- Added checkbox marking, Select all, Clear selection, and selection counts.
- Added multi-item File System copy, move, download, delete, and share operations.
- Made File System action buttons equal in width and responsive to window size.
- Preserved marked items across filtering and cleared them on folder changes.

## 1.6.0

- Embedded File System and Settings in the main application window.
- Added direct and inherited sharing indicators, sharing filters, date filters, and sorting.
- Added transfer speed, progress, estimated time remaining, retry, and cancellation controls.
